# VR-PROTOTYPING: FIRSTAID FOR ROAD ACCIDENTS



## Overview

This repository contains a Unity 6 virtual reality application designed for emergency response training. The architecture utilizes C# scripting alongside the Unity XR Interaction Toolkit and OpenXR to implement interactive mechanics. The application targets the Meta Quest 3 hardware. Virtual reality bridges the gap between theoretical knowledge and practical, stress-tested confidence.

## Implemented Features

### Immediate Wound Management (Bandaging)

This prototype replaces simplified static placement with realistic wound wrapping mechanics.

* The user grasps the bandage roll using a pull tab.


* The tab is pulled until a bandage with a specific, fixed dimension comes off.


* The user holds the prepared bandage and moves to the injured person's arm.


* A 720 degree movement is performed around the arm until the bandage snaps perfectly into place.



### Cardiopulmonary Resuscitation (CPR)

* The user approaches the injured person's torso and is immediately prompted with "Start Compressions".


* The user performs 30 compressions.


* The user is guided solely by a standard BPM beep to maintain rhythm.


* The user must ensure hand placement is centered on the sternum.


* The user must maintain a compression rate of 100-120 per minute at a depth of 5-6 cm.


* When finished, the user is presented with feedback detailing their performance and accuracy.


* The user is prompted to choose a specific music track to play during their second attempt.


* Visual feedback is immediately provided for this second, music-guided session.


* The system shows a visual comparison of both CPR sessions and indicates which one had the better performance.
